## 三、测试中发现并修复的问题

| 问题 | 影响 | 修复 |
|---|---|---|
| 后端 Docker 镜像一开始只复制旧 jar，未包含当前源码 | 页面测到旧逻辑，任务收件箱未显示未提交学生 | 执行 `mvn test package` 后再 `docker compose up -d --build backend`，并在报告中记录正确测试方式 |
| 含人工题的学习单提交后被自动标记为 `graded` | 教师工作台“待评分”为 0，人工题可能被漏批 | 修改 `TaskServiceImpl`：只有全题目可自动批改时才自动置为 `graded`；含人工题保持 `submitted` |
| 学生访问 `/api/tasks/{taskId}/my-result` 返回 403 | 学生无法查看批改详情 | 修改 `SecurityConfig`，将 `/api/tasks/*/my-result` 放行给学生角色，并新增安全测试 |
